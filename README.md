# 尉缭子 — Wei Liaozi

> **还原最原始的《尉缭子》，中文原文 + 英文翻译对照版**

《尉缭子》是中国古代著名兵书，战国时期（公元前475年—公元前221年）尉缭所著。它融合了法家、兵家思想，既讲军事战略战术，也论政治经济制度，是中国古典军事理论的重要著作。原有24篇，本书收录全本。

## 版本对照

本项目以《武经七书》本《尉缭子》24篇为底本，同时收录了《群书治要》卷三十七收录的《尉缭子》选段（天官、兵谈、战威、兵令4篇），作为异文对照。

| 版本 | 时代 | 篇数 | 特点 |
|------|------|------|------|
| 武经七书本 | 北宋 | 24篇 | 最完整的传世本，分为天官、兵谈、制谈等 |
| 群书治要本 | 唐（魏徵编） | 4篇选录 | 唐代抄本选段，文字与武经七书本有重要差异 |
